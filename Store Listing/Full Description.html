When you turn your device, the screen switches between portrait and landscape. But if you're lying on your side, the screen is facing the wrong way. Sideways Mode fixes this, so you can still turn your device to switch between portrait and landscape while lying on your side. This is useful for web browsing or watching videos in bed. Permissions • Modify system settings: To change screen orientation and system auto rotation • Draw over other apps / display system-level alerts: To change incompatible apps' screen orientations • Small app overlay (Sony users only): So you can use a small app to change screen orientation • Internet / Network State / Wake Lock: For anonymous usage reporting (This app was formerly called "Auto Rotation for Lying Down".)
