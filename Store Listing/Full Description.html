Provides automatic screen rotation with support for the user lying sideways. The way this works is when you turn on auto rotation, the direction the screen is facing is assumed to be the direction you are facing. Troubleshooting • If the screen is facing the wrong way, ensure the app you are using supports the expected screen orientation. If it does, turn the screen off and on, which will reset your orientation to upright. • If the screen doesn't rotate immediately after rotating the phone, you might need to wait a little bit. Sometimes Android or apps can lag when the screen orientation changes. • If the screen orientation isn't correct for certain apps, there isn't much you can do about it because apps can override system-wide screen orientation. • If the app crashes, please use the report button so I can fix it in a future version. • If the app otherwise doesn't work correctly, feel free to let me know so I can address the problem(s). You can contact me using the email address in the store listing. Known Issues • Uninstalling doesn't reset the screen orientation. This is an Android limitation. You can work around this by using the uninstall feature within the app. • Doesn't work for apps that request sensor-based orientation modes. • See https://github.com/sampalmer/android-auto-rotate/issues?q=is%3Aissue+label%3Abug+-label%3Ainvalid+is%3Aopen for other current unresolved problems. Permissions • WRITE_SETTINGS: To change screen orientation and system auto rotation • RECEIVE_BOOT_COMPLETED: So this continues working when your device is restarted • SMALLAPP (Sony users): So you can use a small app to toggle auto rotation
